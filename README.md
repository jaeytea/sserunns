# SSERUNNS

> This is an endless runner game inspired by Chrome's T-rex. However, the character that runs here is yours truly.

Ssera has to keep running through an endless hallway, jumping over obstacles and trying to survive for as long as possible.

The game gets progressively faster as the score increases, because apparently running forever wasn't difficult enough. Oh tmi, i dont run irl :P

![SSERUNNS](/src/assets/image.png)

## Tech Stack

- Vanilla TypeScript
- HTML5 Canvas

## Features

- 🏃 Ssera as the playable character
- 🎞️ Sprite-sheet based animation
- 🦖 Endless-runner style gameplay
- 🧱 Randomly spawned obstacles
- 📈 Score-based difficulty progression
- 💨 Increasing game speed
- 🦘 Jump physics with gravity and velocity
- 🎵 Background music and game sound effects
- 🎮 Custom console-inspired UI
- 💡 Scrolling hallway with fluorescent ceiling lights
- 💀 Game-over state and restart

## What I Learned

This is my first experiment with game dynamics/programming, so this project was mostly about figuring things out by actually building them.

I got to work with:

- Canvas rendering and animation loops
- Sprite sheet logistics and frame animation
- Basic game physics
- Collision detection
- Object spawning and movement
- Game state management
- Audio management
- Building a small game architecture in TypeScript

There was definitely some trial and error involved. A lot of it was basically:

> "Okay... why is she doing THAT?"

followed by hit and trial with numbers until it was just there :D
